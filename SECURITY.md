# Security Policy

This HardRectangle fork is maintained by its repository maintainers and community.

## Supported Versions

Security fixes are applied only to the latest stable release.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes    |
| All Past| ❌ No     |

## Scope and Privileges

HardRectangle requires **macOS Accessibility Permissions** (`AXUIElement`) to manage windows.

* **Local Only:** HardRectangle runs entirely locally. It never collects, logs, or transmits window layouts, keystrokes, or personal data.
* **Network Access:** This fork contains no built-in update checker and does not require network access for normal operation.

## Reporting a Vulnerability

Please do not disclose vulnerabilities publicly before the maintainers have had
an opportunity to investigate them.

For sensitive reports, use [GitHub private vulnerability reporting](https://github.com/teamtumnus/HardRectangle/security/advisories/new).
If you already have a private communication channel with a repository maintainer,
you may use that instead.

For non-sensitive security improvements or questions, open a
[GitHub issue](https://github.com/teamtumnus/HardRectangle/issues/new) or submit a
[pull request](https://github.com/teamtumnus/HardRectangle/compare).

### Please Include:
1. A brief description of the issue and potential impact.
2. Step-by-step instructions (or a proof-of-concept script) to reproduce it.
3. Your version of HardRectangle and macOS.
